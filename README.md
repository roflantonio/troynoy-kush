# Botan Cock Games

Лаунчер с тремя браузерными играми и ссылкой на главный проект на Game Jolt. Главная страница открывается по пути `/`.

## Тройной куш

Игра про блеф для троих доступна по пути `/heist/`. Создайте комнату, отправьте приглашение двум друзьям и сыграйте семь раундов.

## Лазерный налёт

Продолжение в жанре шутера с видом сверху доступно по пути `/arena/`. Создайте комнату на троих. WASD или стрелки двигают, курсор прицеливается, ЛКМ стреляет, пробел делает рывок. На телефоне есть два джойстика и кнопка рывка. Музыка и эффекты настраиваются отдельно через меню «Звук».

## Турбо-побег

Онлайн-платформер на 2–4 игроков по пути `/run/`. Первый, кто добежит до порталов всех четырёх трасс, выигрывает. Для движения используйте A и D или стрелки, для прыжка — пробел, W или стрелку вверх. На телефоне есть экранные кнопки.

## Локальный запуск

Установите Node.js 24 и запустите `npm run dev`. Страница откроется по адресу `http://localhost:4173`. Комнаты хранятся в локальной базе SQLite.

## Публикация через GitHub Pages

GitHub Pages обслуживает игровые страницы. Для комнат и подсчёта очков потребуется общедоступный HTTPS-сервер. Его можно развернуть на Cloudflare Workers с базой D1 и привязкой `DB`. Команда `npm run build` собирает воркер в `dist/server/index.js`. Примените миграции из папки `drizzle` по порядку к D1 перед запуском воркера.

1. На сервере укажите `HEIST_PAGES_ORIGIN` как источник GitHub Pages, например `https://account.github.io`. Путь репозитория в эту переменную не входит.
2. В настройках GitHub Pages выберите GitHub Actions. Для своего сервера создайте переменную репозитория `HEIST_API_ORIGIN` с адресом сервера комнат, например `https://game.example.com`.
3. Запустите **Publish game to GitHub Pages** в разделе Actions. Отправьте друзьям ссылку, которую выдаст GitHub Pages.

Игрокам нужен доступ как к странице GitHub Pages, так и к серверу комнат.
